# NEUMAN — Directrices de Desarrollo & Operación

- **Prohibición Estricta:** Prohibido usar la palabra "mermas" en todo el código, copy y metadatos.
- **Términos Obligatorios:** Usar "residuos textiles", "retazos", "sobrantes textiles" o "descartes de confección".
- **Enfoque de Calidad:** Énfasis en nobleza de materiales textiles, acabados prémium y confección cuidada contemporánea B2B (sin términos ni pretensiones de alta costura).
- **Componentes Modulares:** Todo componente nuevo debe alojarse bajo `src/components/`.
- **Validación Estricta:** Validar todos los envíos con Zod antes de llamar a APIs externas.
- **Paleta Oficial:**
  - Dark Chocolate: `#24120C`
  - Warm Cream: `#F7F3EE`
  - Bone / Lino: `#ECE3D6`
  - Sand Gold: `#DFD3C3`
  - Terracotta: `#C86D51`
  - Deep Forest Eco: `#2D3A2F`
- **Comandos de Ejecución:**
  - `npm run dev`: Iniciar servidor de desarrollo en localhost:3000
  - `npm run build`: Validar compilación de producción y tipado TypeScript
